# Simulador de Orçamento de Eventos — RSTCOM

Projeto web mobile-first criado fielmente a partir do Figma **CONTEÚDO RSTCOM (`LANDING PAGE DE ORÇAMENTO`)**.

## 🚀 Como abrir o projeto

Basta abrir o arquivo principal no navegador:
- **[index.html](./index.html)** — Contém o aplicativo completo com todas as seções conectadas, animações e cálculo em tempo real.

Também é possível abrir cada seção individualmente dentro da pasta `sections/`:

1. `sections/01-iniciar/index.html` — Tela inicial (*"Quanto custa seu próximo evento?"*)
2. `sections/02-menu/index.html` — Menu de navegação
3. `sections/03-formato-evento/index.html` — Pergunta 1: Qual o formato do evento?
4. `sections/04-localizacao/index.html` — Onde será o evento? (Campo de endereço/remoto + seletor Maps + botão que surge após preenchimento)
5. `sections/05-quantidade-pessoas/index.html` — Quantas pessoas vão participar? (`500 pax`) + Card **"Quantos dias?"** com calendário dinâmico em 4 etapas (1. Meses → 2. Seleção de dias estilo viagem → 3. Botão Confirmar → 4. Selo de Confirmação)
6. `sections/06-padrao-entrega/index.html` — Padrão de entrega (*Essencial, Corporativo, Premium, Icônico*)
7. `sections/07-o-que-entra/index.html` — O que entra na conta? (Seleção livre com destaque em Bold/Black nos itens ativos)
8. `sections/08-login-signup/index.html` — Telas de Login e Sign up com switch *Remember me*
9. `sections/09-resultado-estimativa/index.html` — **1ª Tela Final**: Faixa de investimento estimada, gráfico *"Onde o dinheiro vai"* e card *Planilha Completa (R$ 49,90)*
10. `sections/10-pagamento-excel/index.html` — **2ª Tela Final**: Informações de pagamento + Pop-up interativo com a **Planilha Excel** mostrando o que cada item custou, edição de quantidades, download `.csv`/Excel e envio por e-mail.
